# DSCI-552-HW3
Time-domain feature extraction and bootstrap analysis on the AReM human activity recognition dataset.
Feature extraction for human activity recognition using the AReM dataset (UCI). Each of the 88 instances contains 6 time series from a wireless sensor network, recorded during 7 activities.

Contents: data loading and cleaning, train/test split, extraction of 7 time-domain features per series (42 total), 90% bootstrap confidence intervals for each feature’s standard deviation, feature selection, and ISLR Exercise 3.7.4.
